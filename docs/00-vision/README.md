# Phase 0 — Vision & Product Strategy

This directory contains the Phase 0 deliverables for the Lumine AI Hedge Fund
platform. Phase 0 defines mandate, product identity, governance, scope, and
success criteria. No architecture, implementation, or technology decisions
belong here — those begin in Phase 1.

## Documents

| Document | Purpose |
|----------|---------|
| `vision-and-mission.md` | Long-term product identity and operating mission |
| `business-goals.md` | Measurable business objectives |
| `user-personas.md` | Primary, accountable, and supporting personas |
| `success-metrics.md` | KPIs and validation gates |
| `scope-and-non-goals.md` | Initial scope and explicit exclusions |
| `product-philosophy.md` | Design principles governing all later phases |
| `long-term-roadmap.md` | Evolution from XAUUSD pilot to internal fund OS |

## Authority

Phase 0 is the authoritative product mandate. Every later phase (architecture,
departments, agents, data, AI, trading, infrastructure, security, testing,
implementation) must trace its assumptions back to decisions recorded here.
If a later phase conflicts with Phase 0, Phase 0 is updated first, then
affected documentation, then code.
